## What this repo is

Personal dotfiles for a NixOS + Hyprland workstation (host: `coder`, user: `leinad`). Two main components:

- `nixos/` — NixOS system + Home Manager configuration managed as a Nix flake
- `nvim/` — Neovim config using Lazy.nvim for plugin management

The `install` script symlinks `nvim/` to `~/.config/nvim` and `nixos/` to `~/nix-conf`.

## NixOS flake

**Rebuild the system after editing any `.nix` file:**

```bash
sudo nixos-rebuild switch --flake /etc/nixos#coder
```

**Update all flake inputs (nixpkgs, home-manager, etc.):**

```bash
cd /etc/nixos
sudo nix flake update
sudo nixos-rebuild switch --flake /etc/nixos#coder
```

**Check what the flake exposes without building:**

```bash
nix flake show /etc/nixos
```

**Collect garbage (old generations):**

```bash
sudo nix-collect-garbage -d
```

## Configuration layout

The flake (`flake.nix`) is pinned to `nixos-25.11` / `home-manager release-25.11`.

**System layer** (`configuration.nix` + imports):
- `configuration.nix` — base NixOS settings (locale, boot, users, services)
- `hardware-configuration.nix` — machine-specific; generated by `nixos-generate-config`, not in templates
- `system-packages.nix` — system-wide packages
- `modules/graphics.nix` — GPU / display driver settings

**Home Manager layer** (`home.nix` imports everything else):
- `packages.nix` — user packages
- `hyprland.nix` — Hyprland compositor config
- `keybindings.nix` — Hyprland key bindings
- `waybar.nix` — top bar
- `rofi.nix` — app launcher
- `ghostty.nix` — terminal emulator
- `zsh.nix` — shell
- `autostart.nix` — session autostart
- `hyprpaper.nix` — wallpaper (expects image at `~/Pictures/wallpapers/nixos-hyprland.jpg`)
- `mako.nix` — notifications (replaced by `modules/swaync.nix`)
- `modules/hyprlock.nix` — screen lock
- `modules/hypridle.nix` — idle daemon
- `modules/swaync.nix` — notification center

## Theme system

`theme.nix` is a pure Nix attribute set (no module — not imported via `imports []`). Visual modules consume it directly:

```nix
let theme = import ./theme.nix; in
```

The palette is "Deep Blue" — dark navy backgrounds (`#0b1017`), blue accents (`#3b82c4`), muted foreground (`#8e9bab`). Change colors here and rebuild; don't patch individual module files.

## Neovim config

Plugin manager: **Lazy.nvim** (bootstrapped in `lua/user/lazy.lua`).  
Each plugin has its own file under `nvim/lua/user/plugins/`.  
Entry point: `nvim/init.lua` → loads `user.options`, `user.keymaps`, `user.lazy`.

LSP stack: Mason (`mason.lua`) + `mason-lspconfig.lua` + `nvim-lspconfig.lua` + `nvim-cmp.lua` for completion.
